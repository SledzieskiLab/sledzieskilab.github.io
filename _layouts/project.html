--- layout: default --- {%- comment -%} A per-publication project page: title → authors → link buttons → teaser → body (figures inline) → BibTeX. Central idea: publication metadata is not restated here. A page names its paper with `citekey:` and inherits title, authors, venue, links, thumbnail and citation from _data/publications.yml, so they can never disagree with /publications/. Any inherited value can be overridden by setting the same key in front matter (see _projects/TEMPLATE.md). `citekey:` is optional — a project not tied to one paper just supplies its own title, authors and venue. The pub lookups below are guarded. {%- endcomment -%} {%- comment -%} ---------- resolve the paper ---------- {%- endcomment -%} {%- assign pub = nil -%} {%- if page.citekey and page.citekey != '' -%} {%- assign pub = site.data.publications | where: 'citekey', page.citekey | first -%} {%- endif -%} {%- comment -%} page.title is never empty — Jekyll falls back to the titleized filename ("Planet Md"). Detect that (it slugifies straight back to the slug) and use the paper's real title instead. Only catches files made by hand; `make project` already writes a real `title:`. {%- endcomment -%} {%- assign _slug = page.url | split: '/' | last -%} {%- assign _title_slug = page.title | slugify -%} {%- assign p_title = page.title -%} {%- if pub and _title_slug == _slug -%} {%- assign p_title = pub.title -%} {%- endif -%} {%- assign p_venue = page.venue | default: pub.venue -%} {%- assign p_year = page.year | default: pub.year -%} {%- comment -%} No status badge here, deliberately — "preprint"/"in press" only earns its keep disambiguating a list of papers; /publications/ still shows it. {%- endcomment -%} {%- assign p_note = page.note | default: pub.note -%} {%- comment -%} Teaser falls back to the publication thumbnail, so a page with no artwork of its own still leads with a figure, not a wall of text. {%- endcomment -%} {%- assign teaser = page.teaser -%} {%- assign teaser_base = '/assets/images/projects/' -%} {%- if teaser == nil and page.teaser_video == nil and pub.image -%} {%- assign teaser = pub.image -%} {%- assign teaser_base = '/assets/images/pubs/' -%} {%- endif -%} {%- comment -%} BibTeX renders when there is a paper to cite it from, or when the page supplies a raw `bibtex:` block itself. {%- endcomment -%} {%- assign has_bibtex = false -%} {%- if pub or page.bibtex -%}{%- assign has_bibtex = true -%}{%- endif -%} {%- assign bib_id = page.citekey | default: p_title | slugify | prepend: 'bib-' -%}
